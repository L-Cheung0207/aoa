# Voice Assistant（私有化部署版） 隐私政策

**更新日期：** 2026年6月17日  
**生效日期：** 2026年6月17日

欢迎使用 Voice Assistant 私有化部署产品（以下简称“本产品”）。

本产品由 **澳门电讯有限公司（CTM）** （以下简称“澳门电讯”、“CTM”或“我们”）开发并提供技术支持，采用**私有化部署**方式，面向澳门特别行政区政府部门、公共机构及企业客户提供。

**澳门电讯承诺：所有语音和文本数据在云端完成处理后即时删除，不留存任何副本。原始语音文件的存储由用户自主决定，存储于客户端本地设备，澳门电讯无权访问。**

我们严格遵守澳门特别行政区第8/2005号法律《个人资料保护法》及相关法规，致力于保护授权用户的个人隐私。

请您在使用本产品前，仔细阅读本隐私政策，了解我们对个人资料的处理方式。如您继续使用本产品，即表示您同意本政策。


## 一、我们处理哪些信息

由于本产品采用私有化部署，且澳门电讯遵循“**云端处理不留存，本地存储用户自主**”的数据管理原则，我们不会存储您的任何语音或文本内容。为提供服务和改进产品，以下信息会在使用过程中被处理：

### 1.1 账号信息
如果授权机构启用了账号管理，系统管理员会为您创建账号，通常包含**用户名、姓名、工号或邮箱**等基本信息，用于身份验证和权限管理。这些信息存储在机构内部的用户目录中，澳门电讯无法访问。

### 1.2 语音数据（ASR识别）
- 当您使用语音输入功能时，您的**实时语音**会被发送至授权机构内部部署的ASR模型进行识别处理，该服务由澳门电讯提供技术支持。
- **云端处理**：语音数据在云端完成实时识别，处理完成后**即时删除，不留存任何副本**。澳门电讯不会以任何形式留存您的原始语音或识别中间结果。
- **本地存储**：如需保存原始录音文件，文件存储于**客户端本地电脑设备**，您可自主决定是否保存以及保存周期（如保存7天、30天或永久）。澳门电讯及授权机构均无法远程访问或获取这些本地文件。

### 1.3 语音数据（长音频转写）
- 长音频文件在内部服务器上分段处理，识别过程中产生的临时文件在处理完成后**即时销毁**。
- 原始音频文件由用户自行保存在客户端本地，系统不留存任何副本。

### 1.4 文本内容
- 您输入的文本、ASR识别结果、AI改写内容等，均在内部服务器完成推理处理，处理完成后**即时删除**，不留存任何副本。
- AI改写功能处理的内容仅用于当次服务，不会用于模型训练或其他任何目的。

### 1.5 使用日志与性能数据（匿名化）
- 为优化产品和改进服务质量（如ASR识别准确率、AI响应速度），澳门电讯可能收集**匿名化**的使用统计数据，例如：功能使用频次、命令识别错误率、系统响应耗时等。
- **此类数据不包含任何您输入的语音或文本内容**，仅以聚合统计形式呈现，无法识别到具体个人或机构。
- 此类数据仅在授权机构内部存储，由机构管理员决定是否导出。澳门电讯仅接收脱敏后的统计报告。

### 1.6 设备与环境信息
客户端程序可能记录设备型号、操作系统版本、软件版本号等信息，用于兼容性调试和故障排查。此类信息仅在本地日志中，不会自动上传至外部系统。


## 二、我们如何使用信息

我们仅在以下目的范围内处理上述信息：

| 目的 | 说明 |
|------|------|
| **提供服务** | 实时语音转写、AI改写、长音频转写等核心功能 |
| **服务质量改进** | 通过分析匿名使用统计数据，优化ASR声学模型和语言模型 |
| **故障排查** | 使用设备日志定位系统问题，保障服务稳定 |
| **合规审计** | 满足授权机构的信息安全管理要求和澳门法律规定 |

**澳门电讯郑重承诺：**
- ✅ 所有个人数据仅用于上述目的，**绝不用于任何营销、推广或商业变现**
- ✅ 所有语音和文本数据在云端**处理完成后即时删除，不留存任何副本**
- ✅ 原始音频文件存储于**客户端本地**，由用户**自主决定保存周期**
- ✅ 澳门电讯**无权远程访问**用户本地存储的任何文件


## 三、信息的共享、转让与公开披露

1. **不对外共享**：由于本产品为私有化部署，澳门电讯不会将任何用户数据共享给第三方。
2. **内部使用**：授权机构内部的管理员可能基于管理需要访问系统日志，但受机构权限政策约束。
3. **法律法规例外**：如澳门特别行政区法律或司法机关依法要求，澳门电讯或授权机构可能不得不提供必要信息，但会在合法范围内最大限度保护您的隐私。


## 四、信息的存储与保护

### 4.1 存储地点
- **云端处理**：所有语音和文本数据仅在云端完成实时处理，处理完成后**即时删除**，不存在数据留存。
- **本地存储**：用户选择保存的原始语音文件存储在**客户端本地设备**上，由用户自主管理。

### 4.2 存储期限
| 数据类型 | 存储位置 | 存储期限 |
|---------|---------|---------|
| 实时语音（ASR识别） | 云端（处理中） | 处理完成后即时删除 |
| 长音频（临时处理） | 内部服务器 | 处理完成后即时销毁 |
| 用户保存的录音文件 | 客户端本地 | 由用户自主决定 |
| AI改写内容 | 云端（处理中） | 处理完成后即时删除 |
| 使用日志（匿名化） | 内部服务器 | 不超过6个月 |
| 账号信息 | 内部用户目录 | 账号注销后删除 |

### 4.3 安全措施
- 数据传输采用内部加密通信（TLS/SSL）。
- 访问控制由授权机构负责，确保仅授权人员可接触系统。
- 澳门电讯定期提供安全更新，修补已知漏洞。
- 私有化部署环境相对封闭，但我们仍建议机构遵循信息安全管理最佳实践。
